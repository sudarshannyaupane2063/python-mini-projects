# Contact Book

A beginner Python project that creates a simple contact book using a dictionary.

## Features

* Add contact
* Search contact
* Delete contact
* Display all contacts
* Prevent duplicate names
* Input validation
* Exit confirmation

## Concepts Practiced

* Functions
* Dictionaries
* Variables
* Conditional statements
* while loops
* for loops
* Nested loops
* `try/except`
* `break` and `continue`
* `return`
* Dictionary methods
* User input
* Input validation
