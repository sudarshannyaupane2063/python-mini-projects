# Password Validator

A beginner Python project that validates a password based on basic requirements.

## Features

* Minimum 8 characters
* No spaces allowed
* At least one uppercase letter
* At least one lowercase letter
* At least one number
* At least one special character
* Repeated validation until a valid password is entered

## Concepts Practiced

* Functions
* Variables
* Conditional statements
* while loops
* break
* `any()`
* Generator expressions
* String methods
* `len()`
* Input validation
